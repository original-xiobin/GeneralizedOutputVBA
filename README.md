# Generalized Output Demo

A lightweight **Excel/VBA automation demo** that transforms inconsistent source data into a clean, standardized output format.

The project demonstrates how VBA can automate repetitive Excel data-processing workflows while preserving source information, applying consistent transformation rules, and flagging records that require manual review.

## Features

- Reads records from a raw-data worksheet
- Removes unnecessary whitespace and cleans inconsistent text
- Standardizes record IDs and revision values
- Normalizes status values into a consistent format
- Validates and formats dates
- Transfers quantities, notes, and other source information
- Flags incomplete or unrecognized records for manual review
- Generates a structured and consistent output table
- Provides a separate macro for clearing previously generated output

## Workbook Structure

### `Instructions`

Provides a brief overview of the demo and instructions for running the converter.

### `Raw_Data`

Contains intentionally inconsistent sample records designed to simulate data received from an external or legacy source.

### `Standardized_Output`

Contains the cleaned and standardized records generated by the VBA converter.

When a record cannot be safely standardized, it is flagged for review rather than having missing or ambiguous information guessed.

## VBA Macros

### `ConvertData`

The main entry point of the application.

The macro:

1. Reads records from `Raw_Data`
2. Cleans and standardizes the source values
3. Performs basic validation and quality checks
4. Flags records requiring manual review
5. Writes the processed records to `Standardized_Output`

### `ClearOutput`

Clears previously generated output while preserving the worksheet structure and column headers.
